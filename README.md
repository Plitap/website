# PLITAP · Сайт

Сайт проекта: представление PLITAP, навигация по направлениям и доступ к подготовленным материалам.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Код сайта, страницы и общие элементы навигации.
- Материалы, предназначенные для сайта.
- Инструкции разработки и публикации сайта.

## Границы направления

Тексты руководств хранятся в [docs](https://github.com/Plitap/docs), правила протокола — в [spec](https://github.com/Plitap/spec), общие визуальные материалы — в [design](https://github.com/Plitap/design). Способ их публикации на сайте ещё предстоит определить. Этот репозиторий пока не содержит работающего сайта.

## Структура

| Раздел | Назначение |
|---|---|
| [`src/`](src/) | Исходный код сайта после выбора технологической основы. |
| [`public/`](public/) | Материалы, которые сайт будет отдавать посетителям без преобразования. |
| [`docs/`](docs/) | Устройство сайта, локальная разработка и процедура публикации. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/website/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
